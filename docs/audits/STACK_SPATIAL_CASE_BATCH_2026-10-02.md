## Identity and compatibility

New audit records store `normalized_case_snapshot`; PostgreSQL reads prefer it over the mutable current case row. The bridge requires this snapshot and never fabricates a historical revision for a legacy evaluation. Canonical recursive object-key sorting makes the case digest independent of JSONB key order while preserving array order. The full spatial input digest includes the service-assigned case/evaluation IDs and mapping; the geometry digest still describes geometry only. The new case-context version uses locale-independent canonical object-key serialization for input and geometry bytes, including nested dictionary parameters and conditions. Arrays retain their physical order. The worker sends those exact bytes to the native hash boundary. Legacy standalone serialization and hashes remain unchanged.

Scientific transport, kinetics and geometry values come from the separately supplied sourced cell input. A mapping establishes semantic association, not measured equality with the lumped model. The result graph describes the existing native fixed-profile assembly and is reconstructed during validation. It does not execute a general symbolic PDE compiler. Case metadata does not alter the numerical equations; native metadata-invariance verification covers that boundary. No database migration is required because the added metadata uses existing JSON snapshots. The runtime version advances to `structured-cell-process-v2` to keep older worker builds from claiming new case-bound input; older queued work still needs its matching v1 worker. History queries select bounded lifecycle metadata without loading scientific manifests.

General 2D/3D catalog identities remain research-only. Old standalone cell input/result records remain readable. Direct restricted-cell intake cannot assert a case association; the authenticated saved-evaluation route assigns it. Legacy research-input API behavior is unchanged. Spatial outputs remain development observations, `decision_eligible: false`, and do not enter the 0D/1D decision response.
