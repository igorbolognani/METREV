# Restricted scalar transport verification kernel

`apps/spatial-sidecar/metrev_spatial/diffusion.py` is a bounded numerical building block for EQ-SP-001, not an MFC/MEC model or an admitted spatial run. It solves `∇·(u c − D∇c) + k c = R` for one dissolved species with positive isotropic or cellwise `D`, or a constant diagonal tensor aligned with the orthogonal grid; constant divergence-free velocity `u`; uniform or cellwise volumetric source `R`; nonnegative scalar or cellwise first-order loss rate `k`; and Dirichlet concentration at every exterior face. Velocity and boundary values remain fixtures. Internal advection uses first-order upwind flux; the flow field is not solved. The `k c` term is a linear disappearance fixture, not electrochemical kinetics or a reaction network. Off-diagonal tensor terms, migration, charge, porosity, membrane, circuit, and coupled electrode fields are absent.

| Item          | Declared meaning                                                                                                                             |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| Grid          | Orthogonal cell-centred 1D/2D/3D, 2–64 cells per axis and at most 4096 cells                                                                 |
| Concentration | `c` in mol/m³; negative computed states fail, never clip                                                                                     |
| Diffusivity   | `D` in m²/s; caller provides a positive isotropic scalar, one isotropic value per cell, or one positive diagonal coefficient per axis        |
| Velocity      | `u` in m/s; optional constant vector in each grid axis                                                                                       |
| Source        | `R` in mol/(m³ s); positive creates species                                                                                                  |
| Linear loss   | `k` in 1/s; nonnegative scalar or per-cell rate consumes species at `k c`                                                                    |
| Flux          | `u c − D∇c` in mol/(m² s); diffusive outflow is half-cell resolved; advective inflow uses its boundary value and outflow uses the cell state |
| Balance       | Integrated diffusive and advective boundary flux minus source; in 1D/2D the omitted cross-sectional measures are 1 m²/1 m                    |
| Solver        | Matrix-free Jacobi-preconditioned conjugate gradient for diffusion, BiCGSTAB for upwind transport, bounded iterations and true residual      |

Internal faces use equal-and-opposite diffusive and first-order upwind advective fluxes. Different adjacent isotropic diffusivities use a harmonic face value, the series resistance of the two half cells; exterior diffusion uses the half-cell distance. Constant diagonal-tensor coefficients act along each grid axis. A two-layer exact solution checks concentration and material-interface flux in 1D/2D/3D. Manufactured affine fields verify axis-specific coefficients in all dimensions, and a separable source profile checks 2D/3D refinement. The manufactured `c=x(1−x)` test with `R=2D` checks coarse/medium/fine solution error in both 2D and 3D. A separate affine advection-diffusion fixture checks spatial refinement and global balance in 1D/2D/3D. Linear loss is checked with a manufactured 1D profile, source/loss equilibrium in every dimension, and transient loss/storage/boundary balances in 1D/2D/3D. These values do not qualify as scientific case measurements. No spatial model status is promoted to executable by this kernel. A production solver requires sourced material coefficients, physical boundary and interface contracts, a solved hydraulic field, tagged Gmsh/DOLFINx mesh integration, electrochemical reaction/charge/circuit coupling, artifacts, persistence and the remaining Phase 2/3 gates.

The same restricted operator supports an implicit Euler fixture for `∂c/∂t + ∇·(u c − D∇c) + k c = R`. A step assembles the old-state storage source and the new-state reaction and diffusive/upwind transport terms, then evaluates storage change, first-order disappearance and both outward fluxes minus production. Time refinement with zero velocity uses `Δt = 0.2, 0.1, 0.05 s` against a `0.01 s` numerical reference at fixed 2D/3D grids and `t = 0.4 s`; the separate transient upwind fixture checks conservation and maximum-principle bounds. These tests do not establish biofilm growth, solved hydraulics, membrane, charge or circuit accuracy.
