# Restricted scalar transport verification kernel

`apps/spatial-sidecar/metrev_spatial/diffusion.py` is a bounded numerical building block for EQ-SP-001, not an MFC/MEC model or an admitted spatial run. It solves `∇·(u c − D∇c) = R` for one dissolved species with positive isotropic `D`, constant divergence-free velocity `u`, a declared volumetric source `R` and Dirichlet concentration at every exterior face. A caller may supply constant or cellwise `D` and constant or cellwise `R`; velocity and boundary values remain constant fixtures. Internal advection uses first-order upwind flux; the flow field is not solved. It has no migration, charge, reaction kinetics, porosity, membrane, circuit, or coupled electrode field.

| Item          | Declared meaning                                                                                                                             |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| Grid          | Orthogonal cell-centred 1D/2D/3D, 2–64 cells per axis and at most 4096 cells                                                                 |
| Concentration | `c` in mol/m³; negative computed states fail, never clip                                                                                     |
| Diffusivity   | `D` in m²/s; caller provides a strictly positive constant or one positive value per cell                                                     |
| Velocity      | `u` in m/s; optional constant vector in each grid axis                                                                                       |
| Source        | `R` in mol/(m³ s); positive creates species                                                                                                  |
| Flux          | `u c − D∇c` in mol/(m² s); diffusive outflow is half-cell resolved; advective inflow uses its boundary value and outflow uses the cell state |
| Balance       | Integrated diffusive and advective boundary flux minus source; in 1D/2D the omitted cross-sectional measures are 1 m²/1 m                    |
| Solver        | Matrix-free Jacobi-preconditioned conjugate gradient for diffusion, BiCGSTAB for upwind transport, bounded iterations and true residual      |

Internal faces use equal-and-opposite diffusive and first-order upwind advective fluxes. Different adjacent diffusivities use a harmonic face value, the series resistance of the two half cells; exterior diffusion uses the half-cell distance. A two-layer exact solution checks concentration and material-interface flux in 1D/2D/3D. The manufactured `c=x(1−x)` test with `R=2D` checks coarse/medium/fine solution error in both 2D and 3D; affine diffusion fields are checked in all three dimensions. A separate affine advection-diffusion fixture checks spatial refinement and global balance in 1D/2D/3D, while a transient upwind fixture checks conservation and bounds in 2D/3D. These values do not qualify as scientific case measurements. No spatial model status is promoted to executable by this kernel. A production solver requires sourced material coefficients, physical boundary and interface contracts, a solved hydraulic field, tagged Gmsh/DOLFINx mesh integration, migration, reaction, charge/circuit coupling, artifacts, persistence and the remaining Phase 2/3 gates.

The same restricted operator supports an implicit Euler fixture for `∂c/∂t + ∇·(u c − D∇c) = R`. A step assembles the old-state storage source and the new-state diffusive/upwind transport terms, then evaluates storage change plus both outward fluxes minus source. Time refinement with zero velocity uses `Δt = 0.2, 0.1, 0.05 s` against a `0.01 s` numerical reference at fixed 2D/3D grids and `t = 0.4 s`; the separate transient upwind fixture checks conservation and maximum-principle bounds. Neither test establishes transient reaction, biofilm growth, solved hydraulics, membrane, charge or circuit accuracy.
