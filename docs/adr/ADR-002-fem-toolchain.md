# ADR-002 — FEM and mesh toolchain

Status: Gmsh chosen for development meshes; coupled FEM evaluation pending. Date: 2026-09-27.

Candidate stack: Gmsh physical groups for subdomains/facets, DOLFINx for finite element forms and mesh/tag import, and PETSc KSP/SNES for linear/nonlinear solves. The [DOLFINx Gmsh demo](https://docs.fenicsproject.org/dolfinx/main/python/demos/demo_gmsh.html) demonstrates physical groups and tagged mesh import; [Gmsh documentation](https://gmsh.info/doc/texinfo/) explains that physical groups control exported elements; [PETSc KSP](https://petsc.org/release/manual/ksp/) exposes linear solvers and [SNES](https://petsc.org/main/manualpages/SNES/) nonlinear solves. These are interface evidence, not proof of version compatibility or suitability for METREV.

The development mesh CLI pins Gmsh 4.15.2; its official [API](https://gmsh.info/doc/texinfo/) documents physical groups and `getElementQualities(..., "minSICN")`. The candidate Docker base is the official [DOLFINx v0.10.0-r1 image](https://github.com/FEniCS/dolfinx/pkgs/container/dolfinx%2Fdolfinx/572672494?tag=v0.10.0-r1), pinned by its multiarch digest. DOLFINx 0.10 changed [Gmsh import APIs](https://docs.fenicsproject.org/dolfinx/v0.10.0/python/release_notes.html). The `validate-spatial-toolchain` CI gate builds this exact container, imports a tagged METREV 2D `.msh` and a synthetic tagged tetrahedral 3D `.msh` through the versioned `MeshData` API, and solves affine Poisson fixtures in both dimensions with PETSc. The cube verifies toolchain wiring only; it is not a canonical METREV cell geometry or an admitted production solver.

Alternative: a finite volume core for conservative flow/species balances with explicit coupling; it may simplify cellwise flux bookkeeping but would require a separate verified charge/reaction/interface implementation. After the smoke, a production path still needs tagged region/boundary forms, conservative species and charge physics, 1D/2D manufactured and mesh-refinement cases, sourced coefficients and runtime isolation. Local development lacks Docker; CI supplies the pinned container gate. Do not mark P04 or P05 complete.
